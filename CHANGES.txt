== Next (not released yet)
Shop tools the shop actually runs, beside the calculators
- Threads and Taps: the shop's taps for the selected thread, from the
  toolbooks. Picking one fills the tap card: thread, cut or form tap, and
  the toolbook's own SFM (391-392 SFM/FPT lines). A tap the chart doesn't
  list (1 1/8-12, 3/8-18) goes in as a custom thread, with its own drill
  range. The shop's drills inside the tap-drill range are listed too.
- Milling and Drilling: the shop's drills or mills at the entered
  diameter. Picking one with a toolbook SFM runs the calculator at it (and
  at its FPT on mills; on drills the toolbook doesn't say per rev or per
  flute, so the feed is left to the preset).
- The toolbook importer reads tap threads written the shop's ways (10-24,
  1-1/8 - 12, 1.8750-12, 1/2" NPT, 12 X 1.75 MM), form taps, and the
  SFM/FPT line. Mills listed with one insert (solid or screw-on heads) no
  longer get a tooth count of 1.

== 1.2.0
Shop tools, Windows app and a second calculation audit
- Shop Tools (Shop Setup): the shop's own tools from the Hive toolbooks
  (391-392, 464-465, 467-468, 469-471, 476-477, 487-488, 372, 459).
  Search by description, part or maker; pick a tool to see its parts,
  machines and any proven S/F from the toolbook, and send its diameter,
  teeth or chamfer angle to Milling and Drilling, Spot, Chamfer or Thread
  Mill. npm run import:hive writes shop/tools.js, which is never
  committed (job and part numbers); only the Windows app and the Forge
  copy carry it. The website has no Shop Tools card.
- Windows app: tools/release-windows.sh builds a per-user installer (no
  admin) with Matt's Sine icon.
- External thread-mill feed is compensated on the thread major,
  (major + tool) / major, per Kennametal TMS. The previous minor-based
  ratio overfed the major diameter.
- 7/16-14 tap drill is U (.368, 75 % thread); 23/64 gave 84 %. A test now
  keeps every UNC, UNF and metric chart tap drill at 65-80 % thread.
- Fixed workbench layout: categories on the left, the latest result on
  the right.
- The offline cache name moved to mb-sine-v3 so installed copies pick up
  the new files.
- Thread standard, size, and tap style are selected once and shared by the
  tap drill, tap speed/feed, thread-mill, and NPT helpers. Removed repeated
  selectors that could leave the calculations on different thread sizes.
- Feed labels now state inches per revolution/tooth and IPM, including when
  diameter inputs use metric units. Endmill results distinguish target chip
  load from the reduced programmed chip load after radial chip thinning.
- Switching thread-mill tool/depth units now converts the values while
  preserving their physical size.
- Peck Guide reports depth-to-diameter ratio instead of implying a universal
  material-only peck size. Tool geometry, coolant, chip form, and the control
  determine the peck cycle.
- Geometry inputs now reject zero or invalid values and report consistent
  unit labels. Fraction input rejects zero denominators and trailing text.

== 1.1.0
Ready for MB Forge and the MB suite
- Sine runs inside MB Forge. npm run build:forge writes dist/forge/sine/,
  a copy Forge can carry in its app (see docs/FORGE.md). Inside Forge it
  uses Forge's graphite colours and font, needs no network and has no
  service worker. The website looks and works as before.
- No inline scripts or onclick handlers: buttons name their calculation in
  data-click / data-change and js/actions.js runs it. Forge's security
  policy blocks inline handlers, so this is what lets every button work
  there. The Forge build refuses to finish if the page would break it.
- Inside Forge, each new result is also sent to the Forge window as a
  message (label, plain text, the Copy Result note). Forge decides what to
  do with it; Sine never acts on messages sent to it.
- Colours are named once at the top of styles.css, so the Forge theme
  changes names, not rules.
- Open the site with ?host=forge to preview the Forge look in a browser.
- The offline cache name moved to mb-sine-v2 so installed copies pick up
  the new files.

Calculation audit (every section checked against standard references)
- Form-tap drills were too small: they used the cutting-tap constant.
  Form taps now use 0.68 x pitch at 55-75 % thread, so 1/4-20 gives #1
  (.228) instead of about #3 (.213), and M6 x 1 gives 5.56 mm.
- Thread mill feed was the feed at the cutting edge. The program needs the
  feed at the tool centerline: a 1/2-13 internal thread with a .375 mill
  showed 8.1 IPM where 2.025 IPM is right (4x too fast). Both are shown now,
  and the machine-limit check uses the centerline feed.
- Tap Drill Check: the smallest and largest drills are always inside the
  calculated range, the thread-percent range is shown, and cutting taps
  also show the standard chart tap drill.
- 1/8-27 NPT uses the shop-selected R (.339 inch) tap drill.
- Chamfer depth says "from the tool tip" when a tip diameter is entered.
- Checked and unchanged: all 106 number and letter drill sizes, UNC, UNF
  and metric thread data and chart tap drills, speeds, chip thinning,
  helix, circular interpolation, effective diameter, scallop, true
  position, bore stock, taper, bolt circle, triangle and conversions.

Cleaned up
- Countersink Depth Helper is part of Chamfer and Countersink Depth: give
  a size per side or a top diameter (82 and 100 degree tools added).
- Spot and Center Drill Helper and Drill Point Depth were the same
  calculation: now one Point and Spot Depth card (drills 118/135/140,
  spot drills, center drill). The Peck Guide has its own card.
- Removed the 15/30/45/60 chamfer buttons (the angle list has them),
  Basic Shop Math (percent of a number), repeated formula-table rows,
  duplicate code and unused styles.
Saved machine profiles and settings are unchanged.
